# VELQORA Web Services Bot

Telegram bot for VELQORA website-service leads.

## Files
- bot.py — complete bot
- requirements.txt — Python dependency
- .env.example — names of required secrets

## Required secrets
BOT_TOKEN = your BotFather token
ADMIN_CHAT_ID = your Telegram numeric chat ID

Never publish either secret in GitHub.

## Run
pip install -r requirements.txt
python bot.py
